### 2. Help with Vercel Deployment

**Prompt:** "The build was succesfull but after testing it seems that the admin panel gives me a code 500 (with images of the console)"

**Initial Error:** 
```
Failed to load resource: the server responded with a status of 500 ()
ENOFS: read-only file system, open '/var/trash/data/trashcans.json'
```

**Root Cause Analysis:**
- Vercel uses read-only filesystem
- App was trying to write to JSON file using `writeFileSync()`
- Attempted solution with Vercel KV (Redis) failed - KV not available on free plan

**Database Solution - Neon PostgreSQL:**

**Steps Completed:**

1. **Database Setup**
   - Connected Neon PostgreSQL via Vercel Marketplace
   - Environment variables automatically configured by Vercel
   - Connection string added to `.env`

2. **Prisma ORM Integration**
   - Installed Prisma 5 (stable version for this project)
   - Created Prisma schema with TrashCan model

3. **Database Migrations**
   - Created initial migration: `20260112144137_init`
   - Schema synced with PostgreSQL
   - Database created and ready

4. **Data Seeding**
   - Created seed script (`prisma/seed.ts`)
   - Populated database with 6 trash can locations:
     - Gravensteenstraat
     - Korenmarkt
     - Citadelpark
     - Sint-Pietersplein
     - Vrijdagmarkt
     - Gentbrugge Meersen

5. **API Route Migration**
   - **GET /api/trash-status** - Fetches all trash cans from database
   - **PUT /api/trash-status/[id]** - Updates trash can status in database
   - Both routes now use Prisma instead of file system operations
   - Type-safe database queries with full TypeScript support

6. **Vercel Build Fix**
   - Added postinstall script to package.json: `"postinstall": "prisma generate"`
   - Ensures Prisma client is generated during Vercel build process
   - Resolves `PrismaClientInitializationError` on deployment

**Technology Stack:**
- **Database:** Neon PostgreSQL (serverless, EU-Central-1)
- **ORM:** Prisma 5.22.0
- **Type Safety:** Full TypeScript support with Prisma Client
- **Singleton Pattern:** Proper Prisma client initialization in `lib/prisma.ts`

**Outcome:** ✅ Full production deployment with persistent database
